# Invoice fonts

The PDF generator embeds these unmodified Noto font files so downloaded bills render offline:

- `NotoSans-Regular.ttf` and `NotoSans-Bold.ttf` for Latin text.
- `NotoSansBengali-Regular.ttf` for Bengali text, including shaped Bengali syllables.

Source: Debian `fonts-noto-core`, upstream Google Noto fonts. See `LICENSE-NOTO.txt` for the included copyright notices and SIL Open Font License 1.1. These files are invoice assets, independent of the existing frontend font packages.
